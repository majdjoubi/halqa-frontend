# Sound Assets

## lesson-alert.mp3

This file is used to alert the teacher when a lesson is about to start (5 minutes before).

### How to add the sound file:
1. Download or create an MP3 alert sound (recommended: short notification sound, 1-3 seconds)
2. Name it `lesson-alert.mp3`
3. Place it in this folder: `src/assets/sounds/`

### Recommended free sources:
- https://freesound.org/ (search for "notification" or "alert")
- https://mixkit.co/free-sound-effects/notification/
- https://www.zapsplat.com/sound-effect-category/notification-sounds/

### Note:
If no sound file is present, the audio alert will fail silently without affecting the application.
